# v0.1 검증 기록

검증일: 2026-11-24 (Asia/Seoul). Python 3.12.14, Linux.

## 실행한 검증

- `python -m unittest discover -s tests -v`: 34개 자동 테스트 통과.
- `python -m examples.demo`: 가상 대화 2개 / 원문 구간 2개 / 정해진 시험 3개를 사용한 인계 시뮬레이션 통과.
- 테스트 안에서 별도 Python 프로세스로 CLI import와 MCP stdio initialize → initialized → tools/call 실행.

## 확인한 동작

- 원본 JSON 파일을 바이트 단위로 복원하고 SHA-256 비교.
- 한글 원문, 수정된 대화 버전, 모든 mapping 분기와 알 수 없는 메타데이터 보존.
- 잘못된 가져오기 전체 거부, 중복 import 멱등성.
- 수신 전 읽음 확인 거부, 잘못된 토큰/해시 거부, 새 AI 세션은 읽음 0에서 시작.
- 원문에 없는 인용 거부, 근거가 있는 해석 기록은 덮어쓰지 않고 추가.
- 인계 질문 미등록·오답·잘못된 근거 시 전환 거부.
- 인계 중 새 메시지/수정본이 들어오면 오래된 스냅샷 활성화 거부.
- 원문 변조 및 구간 삭제 감지.
- 잔여 5% 경계, 긴 다음 응답 예상 시 조기 준비, 동일 준비 요청의 중복 세션 생성 방지.
- 이미 다른 후속 세션으로 전환됐다면 이전 선행 세션 기반 전환 거부.
- 다른 프로젝트로 세션 연결 거부.
- 첨부 참조가 있는 대화는 텍스트만 읽고 활성화하지 않음.
- 구간 경계를 넘는 검색 및 같은 구간 내 여러 검색 결과의 페이지 이동.

## 검증하지 않은 범위

- 실제 사용자 대화 데이터는 가져오지 않았음.
- 실제 모델 API 호출 또는 외부 AI 클라이언트 연결은 실행하지 않았음.
- 데모 정답은 고정값이므로 AI 이해도·기억력 점수가 아님.
- 완벽한 이해/영구 기억/숨겨진 모델 상태 이식은 제공하지 않음.
- ChatGPT iOS/웹 자동 동기화, 잔여 용량 감지, 새 방 생성은 미구현.
- 첨부파일 인식은 알려진 필드에 대한 휴리스틱이며 모든 내보내기 포맷의 완전성은 보증하지 않음.
- 이미지·PDF·음성 내용 판독, 실시간 메시지 라우터, 모델 사용량 제한은 별도 연결 필요.
- Windows 실행 및 `publish.ps1` GitHub 등록은 이 Linux 환경에서 실행하지 않았음.
- GitHub 공개 저장소 `changjin123123/chat-continuity` 생성 확인. 원격 CI는 실행하지 않았음.

API 비용이 발생하는 호출은 실행하지 않았습니다.
